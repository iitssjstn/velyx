# Vidalune app

The Vidalune app for Android (Expo, React Native, Expo Router). It talks to a Vidalune server through
the API described in the main README ("Signing in from an app").

- Routes live in `src/app/` (Expo Router); everything else in `src/lib/` and `src/components/`.
- `src/lib/` holds logic without React Native imports where possible, so it is tested with Vitest
  (`npm test`). Keep it that way.
- Install packages with `npx expo install <package>` (set `EXPO_OFFLINE=1` when the Expo API is
  unreachable) so versions match the Expo SDK.
- `android/` is generated by `npx expo prebuild`; never edit or commit it. Native settings belong in
  `app.json` and config plugins.
- The APK is built by `.github/workflows/android.yml`.
- Keep the version in `package.json` and `app.json` (`version`, `android.versionCode`) equal to the
  server's version.
